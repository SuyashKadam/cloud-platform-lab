# cloud-platform-lab

A hands-on lab where I rebuild, at small scale, the platform work I do as a cloud engineer: secure
foundations, keyless CI/CD, automated security remediation, cost-optimized EKS, observability, workload
identity, a self-service developer platform, and a private GenAI/RAG stack on AWS.

Each module has working code, an explanation of the concepts, a "prove it works" section, and the
questions I should be able to answer about it.

## Modules

| # | Module | Topics | Runs on | Status |
|---|---|---|---|---|
| 0 | [Foundation](./00-foundation) | Terraform remote state (S3 + native locking), private VPC, VPC endpoints, KMS, Budgets | AWS | ready |
| 1 | [GitHub OIDC](./01-github-oidc) | OIDC federation, STS, trust policies, least privilege, no long-lived keys | AWS + GitHub Actions | ready |
| 2 | Security auto-remediation | EventBridge, CloudTrail events, Step Functions, Python Lambda | AWS | planned |
| 3 | EKS cost optimization | EKS, Karpenter, Graviton (arm64), Spot, consolidation | AWS | planned |
| 4 | Observability | OpenTelemetry, distributed tracing, K8sGPT, Slack alerts | Kubernetes | planned |
| 5 | Workload identity | SPIFFE/SPIRE, SVIDs, mTLS between services | Kubernetes | planned |
| 6 | Internal developer platform | Crossplane (XRDs, Compositions), Backstage templates | Kubernetes + AWS | planned |
| 7 | Private RAG | Amazon Bedrock Knowledge Bases, OpenSearch Serverless, PrivateLink, KMS | AWS | planned |

Work through them in order. Later modules reuse the state bucket, VPC, KMS key and OIDC role from 0 and 1.

## Prerequisites
- An AWS account, with the AWS CLI v2 configured (`aws sts get-caller-identity` works)
- Terraform 1.10 or newer
- Linux / WSL2 shell, git
- Region: `us-east-1` (change the `region` variable everywhere if you use another)

Install steps are in [00-foundation/README.md](./00-foundation/README.md#run-it).

## Cost rules I follow
- The $20/month budget alert from Module 0 goes in first.
- Every module ends with a clean-up section. Anything billed per hour (EKS, OpenSearch Serverless,
  interface endpoints) gets destroyed at the end of the session.
- Each module README states its rough cost up front.
